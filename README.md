# regions

Бесплатный навигатор федеральных и региональных мер поддержки семей для проекта «Анна про пособия».

## Первая версия
- выбор региона;
- количество членов семьи и детей;
- возраст каждого ребёнка;
- беременность и ребёнок с инвалидностью;
- предварительная подборка мер;
- переход к персональным услугам.

Важно: сайт не утверждает, что конкретная выплата «положена». Он показывает меры, которые стоит проверить. База мер должна заполняться по актуальным официальным источникам.


## Контроль качества данных

Перед публикацией региональной меры проверяются:
1. официальный региональный источник;
2. конкретный действующий НПА;
3. актуальная редакция;
4. дата вступления правила в силу;
5. территория действия;
6. категория семьи и специальные условия;
7. актуальный размер или формула расчёта;
8. официальный способ обращения;
9. дата последней проверки.

Неподтверждённые и устаревшие карточки получают `needs_review` и не участвуют в пользовательской выдаче.

## Принцип выдачи

Навигатор не выносит решение о праве на выплату. Он показывает меры, которые стоит проверить по введённым данным. Это позволяет не обещать назначение там, где орган должен дополнительно проверить доход, имущество, занятость, гражданство, документы или иные условия.
