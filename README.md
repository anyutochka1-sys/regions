# regions

Бесплатный навигатор федеральных и региональных мер поддержки семей для проекта «Анна про пособия».

## Первая версия
- выбор региона;
- количество членов семьи и детей;
- возраст каждого ребёнка;
- беременность и ребёнок с инвалидностью;
- предварительная подборка мер;
- переход к персональным услугам.

Важно: сайт не утверждает, что конкретная выплата «положена». Он показывает меры, которые стоит проверить. База мер должна заполняться по актуальным официальным источникам.
