# Обновление десяти регионов — 19 октября 2026

Работа выполнена в существующем репозитории `anyutochka1-sys/regions`. Перед обновлением сверены история GitHub, предыдущие источники и очереди проверки.

Приняты 10 новых версий обзоров, сохранены все 185 разделов, включая таблицы. Это число разделов, а не число отдельных мер. Тексты исходников не являются подтверждением достоверности содержащихся в них утверждений.

Новые версии четырёх ранее полученных областных обзоров сопоставлены с существующими темами. Прежние 4 опубликованные карточки, результаты проверки и старые источники сохранены. Для шести остальных регионов создана привязка источников и очередь сверки.

## Существенные расхождения

- Югра: в присланном тексте ошибочно указаны два маткапитала по миллиону и отмена покупки автомобиля. Официальное разъяснение от 28.08.2026 описывает другую программу и только предложение увеличить сумму. В карточку не включены спорные суммы.
- Херсонская область: заголовок говорит о введённом в конце 2026 капитале, а текст ссылается на майский анонс. Без принятого акта программа не показана как действующая.
- Воронежская область: сам обзор содержит разные суммы маткапитала и несходящуюся индексацию. Предыдущее уточнение сохранено.
- ЕДВ для рождённых до 2023 нельзя показывать как текущую выплату на детей младше 3 лет в октябре 2026.
- ЯНАО: расходятся сроки повышенной выплаты за контракт. Региональная часть не смешана с федеральной.

## Проверки

- Штатный `Data quality` из GitHub workflow: успешно по 31 файлу данных.
- Синтаксис `app.js`: успешно.
- Полнота десяти исходников проверена по SHA-256; все 185 разделов связаны с пунктами сверки.
- Все прежние поля проверок четырёх областей сохранены; новые ID уникальны.
- Загрузка и формирование карточек всех десяти регионов проверены в Node VM с данными репозитория; экранирование HTML проверено. Визуальная браузерная проверка не выполнялась.

Полная юридическая проверка всех мер из обзоров не завершена. Отметка `conditions_confirmed` описывает только явно указанный объём сверки, а не индивидуальное решение о праве на выплату.
