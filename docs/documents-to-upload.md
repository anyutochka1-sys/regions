# Документы для подгрузки: сверка регионов по алфавиту

Обновлено: 2026-10-19.

Начат первый проход: **Алтайский край → Амурская область → Архангельская область → Астраханская область**. Далее — **Белгородская область**, затем Брянская область. Порядок названий взят из списка сайта; республики проверяются на букву «Р».

Обзоры получены по всем **89 регионам**. В этом проходе разобраны обзоры и прежние замечания первых четырёх регионов. **Полные действующие тексты для подгрузки — 40 актов с подтверждёнными официальными реквизитами**. Сначала нужно уточнить **ссылки на акты — 29**, а также **темы без установленных оснований — 35**. Полная юридическая проверка ни одного региона в этом проходе ещё не завершена.

Из прежнего общего файла «Dokumenty_i_utochneniya_po_regionam.xlsx», версия 9, сохранены **808 уникальных пунктов** с прежними кодами, статусами и найденными ссылками: [история уточнений](../data/reviews/previous-clarifications.json). Проверен также общий файл источников версии 26. Это сохранённая история; её старые статусы не означают новую проверку в октябре. Обзоры повторно присылать не требуется.

## Как пользоваться списком

В первой таблице каждого региона — что подгрузить: полный текст, действующий на 19.10.2026, все приложения и последующие изменения, если они ещё не включены в редакцию. Один акт нужен один раз, даже если связан с несколькими мерами. Ссылка на разъяснение подтверждает реквизиты, но не заменяет полный НПА.

Во второй таблице — реквизиты, которые ещё нельзя считать установленными. Не нужно искать документ вслепую по ошибочному номеру: сначала сверяются дата, орган и предмет регулирования. Ненайденный акт не доказывает отсутствия меры.

Факт отсутствия полного текста относится к доступному своду материалов и архивному реестру. Поисковая выдержка и страница МФЦ не отмечаются как полученная действующая редакция НПА. Непроверенные сведения из обзоров не публикуются как подтверждённые карточки.
